# Catatan jarak manual pada demo

Tahap rekayasa FR-04, bukan pengukuran penglihatan. Pengguna boleh menambahkan jarak aktual dalam cm tanpa target klinis yang ditentukan aplikasi. Konversi ke mm hanya untuk penyimpanan; ukuran simbol demo tetap. Catatan diberi label dikonfirmasi pengguna, bukan terverifikasi otomatis.

Editor opsional di Persiapan mewajibkan angka positif finite, pengukuran fisik dari bidang layar ke mata, posisi stabil, serta alat jawab bisa dipakai dari posisi tersebut. Mode sendiri menyebut keyboard nirkabel/alat input yang dapat dijangkau; pendamping memasukkan jawaban. Selama editor terbuka, latihan diblokir sampai catatan disimpan atau dilewati secara eksplisit.

Mengubah/menghapus catatan jarak mengosongkan respons kedua mata dan latihan. Tombol Posisi berubah selama latihan/tes/pergantian mata mengembalikan ke Persiapan dan membuang catatan jarak. Perubahan kalibrasi membuang catatan jarak juga. Sesi baru dan perubahan mode membersihkan seluruh catatan. Tidak ada penyimpanan server, target jarak default atau skor klinis.
