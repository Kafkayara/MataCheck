# Interupsi sesi demo

Cakupan: bagian validitas sesi protokol; melanjutkan fitur yang sudah disetujui. Tambahkan penanganan blur/visibilitychange pada demo aktif. Kosongkan jawaban mata aktif, sembunyikan simbol, wajibkan tombol Ulangi mata ini. Respons mata yang selesai dipertahankan bila kalibrasi tidak berubah. Jeda manual tanpa meninggalkan halaman tetap mempertahankan progres demo yang ada.

Uji: handler asli dalam VM untuk mata kiri/kanan, kejadian berulang, non-trial, dan perpindahan tab saat jeda manual; fixture DOM untuk simbol tersembunyi, jawaban diblokir dan pengulangan mata. Pertahankan aturan kalibrasi yang lebih ketat (perubahan tampilan menghapus kedua mata). Tidak menambahkan parameter pengukuran klinis.
